# Web Development Projects

This repository contains a collection of frontend learning projects built with HTML, CSS, JavaScript, and React.

## Folder Structure

- `Basic-React/`
  - `01_my-react-app/` - Basic React app starter.
  - `03_vite_counter/` - Counter app built with Vite and React.
  - `04_tailwind/` - React project using Tailwind CSS.
  - `05_bgChanger/` - Background color changer app.
  - `06_passwordChanger/` - Password generator/changer app.
  - `07_Currency/` - Currency conversion app.
  - `08_ReactRouter/` - React Router example app with React 19 and Tailwind.
  - `viteapp/` - Additional Vite React demo project.

- `Html/`
  - HTML practice pages for layouts, forms, lists, media, and responsive design.
  - Includes `style.css` and many example pages.

- `Javascript/`
  - JavaScript lessons and examples.
  - Includes basics, arrays, objects, functions, DOM examples, and advanced topics.

- `Js_projects/`
  - Small interactive JavaScript projects.
  - Example folders include `1_ColorChanger/`, `2_BMI/`, and `3_DigitalClock/`.

- `Project/`
  - Additional project work with HTML, CSS, and images.

- `WebD/`
  - A nested copy of Web Development practice files and resources.

## What I Have Done

This workspace shows the progress of learning frontend development through:

- building static HTML pages and responsive layouts
- practicing CSS styling, flexbox, positioning, and transitions
- writing JavaScript logic, DOM event handling, and functions
- creating small web apps like counters, color changers, and calculators
- building React apps with Vite, Tailwind CSS, and React Router

## How to Access the Projects

1. Open this repository folder in VS Code.
2. Choose a project folder from the list above.

### For HTML/CSS projects

- Open the `.html` file in your browser.
- Or use a Live Server extension in VS Code to preview pages locally.

### For JavaScript practice files

- Open the `.html` file that includes the `.js` script.
- Use the browser console to see output or interact with the page.

### For React projects

1. Open the React project folder, for example `Basic-React/08_ReactRouter/`.
2. Install dependencies:

```bash
npm install
```

3. Start development server:

```bash
npm run dev
```

4. Open the local URL shown in the terminal.

> Note: `Basic-React/08_ReactRouter/` now has dependencies installed, so the `react-router` commands should work after `npm install`.
